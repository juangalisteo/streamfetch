STREAMFETCH v1.0.0 - STREAMED VIDEO DOWNLOADER
(Espanol: lee 00_LEEME.txt)

WHAT IT IS FOR
Downloads videos from websites without a download button (classes, courses,
webinars...) using the .m3u8 link your browser receives.

FIRST TIME
1. Copy the WHOLE STREAMFETCH folder wherever you want.
2. Double-click 02_ACTUALIZAR.cmd (installs yt-dlp and the subtitle AI).
3. Double-click 03_CREAR_ACCESO_DIRECTO.cmd for a desktop shortcut.

HOW TO GET THE VIDEO LINK
1. Open the video page in Chrome, Edge or Firefox.
2. Press F12 and open the Network tab.
3. Type m3u8 in its filter box.
4. Press Play on the video: a line with m3u8 appears.
5. Right-click it -> Copy -> Copy URL.
IMPORTANT: these links expire within hours. Copy it right before downloading.
(The same steps are in the window: "How do I get the link?" button)

HOW TO USE IT
1. Double-click 01_DESCARGAR.cmd.
2. 01 Video link: paste the link (one per line if there are several).
3. 02 Origin page: leave it empty (automatic) or type the video's website,
   for example https://www.tella.tv/
4. 03 Format: MP4 (video) or MP3 (audio only).
5. 04 Quality: 720p, 1080p or Best. SRT button: green = subtitles too.
6. 05 Name: for example "Class 3 - Web design". Empty = automatic name.
7. Press Download. Files go to the DOWNLOADS folder.

IF YOU GET AN ERROR
- "The link has expired" or "Access denied": copy the link again
  (steps above) and check the origin page.
- "Protected with DRM": that video can't be downloaded.

RESPONSIBLE USE
Only download videos you have access to and permission to keep.
StreamFetch does not bypass DRM, logins or paywalls.
